# pgLite docs

Current reference:

- `CREDENTIALS_FILE_FORMAT.md` — `.pgconsole/credentials.json` format, `ssl` modes, CA bundles
- `MULTI_ENVIRONMENT.md` — how environments are loaded and selected
- `query-execution-architecture.md` / `TECHNICAL_DOCUMENTATION.md` — query path internals
- `SHIP_BLOCKERS.md` — close-out status of the original production-readiness review
- `ISSUES/` — small one-off issue notes
- `features/` — design notes for features that were built
- `mockups/redesign.html` — the UI redesign mockup

`archive/` holds planning docs, audits and reviews from earlier phases. They
are kept for history and no longer describe the code. Issue statuses live in
`../issues/README.md`.
